# 잿빛 매와 별의 장부

> 1,200시간 동안 모바일 RPG를 붙잡은 남자가, 그 게임 1장에서 죽는 몰락 검가의 엑스트라로 눈을 뜬다.
> 원작 지식으로 살아남으려던 그는 곧 알게 된다. 그 '원작'이 공략집이 아니라 — 지난 회차에 바쳐진 누군가의 유서였다는 것을.

브라우저에서 바로 실행되는 서브컬처 턴제 RPG. 서양 판타지 귀족·기사 아카데미를 무대로 한 빙의·생존·메타 미스터리.
순수 HTML / CSS / JavaScript, 빌드 도구와 외부 CDN 없음.

---

## 실행법

1. 저장소를 내려받는다.
2. **`index.html`을 더블클릭**해 브라우저(Chrome, Edge, Firefox, Safari)로 연다. 끝.
   - 서버가 필요 없다(`file://`로 동작). 모든 데이터는 `<script>`로 불러오므로 CORS 문제가 없다.
   - 데스크톱(가로)과 모바일(세로) 모두 지원한다. 모바일에서는 파일을 기기에 옮겨 열거나, 아무 정적 호스팅(GitHub Pages 등)에 올려 열면 된다.
3. 저장은 브라우저 `localStorage`에 된다. (사생활 보호 모드처럼 저장소를 쓸 수 없는 환경에서는 메모리에만 저장된다.)

## 조작법

### 이야기

| 입력 | 동작 |
|---|---|
| 클릭 · 탭 · `Space` · `Enter` | 대사 넘기기 (글자가 나오는 중이면 한 번에 표시) |
| `Ctrl` 누르고 있기 / [스킵] | **이미 읽은 대사만** 빠르게 넘기기. 처음 보는 대사·선택지·전투에서 멈춤 |
| `A` / [오토] | 자동 진행 (대기 시간은 설정에서) |
| `L` / [로그] | 대사 로그 (최근 300줄) |
| `N` / [수첩] | 기록한 이름, 단서, 동료 상태 |
| `Esc` / [메뉴] | 메뉴 · 창 닫기 |
| `1`~`4` | 선택지 고르기 |
| [저장] / [불러오기] | 수동 슬롯 3개 + 자동 저장 |

- **자동 저장**: 장이 바뀔 때, 전투 직전·직후, 선택지를 고른 직후. 타이틀의 [이어하기]는 가장 최근 저장을 불러온다.
- **설정**: 텍스트 속도(10~100자/초·즉시), 오토 대기, 스킵 범위(기본: 읽은 대사만), 전투 연출 속도(1·2·4배·즉시), 화면 흔들림, 난이도(쉬움/보통/어려움, 언제든 변경).

### 전투

1. 동료 카드를 누르고(속도 순으로 자동 선택됨) → 아래 **기술 카드**를 고르고 → 위쪽 **적의 행동(주사위 칸)** 을 누른다.
2. 동료 카드에 결과 예측이 표시된다: `격돌 · 승률 72%` / `가로채기` / `적이 가로챔` / `일방 공격 (느려서 막지 못함)`.
3. [전투 개시] (`Enter`). [자동 편성](`Q`)은 비어 있는 동료의 행동을 AI가 채운다. [자동 전투]는 매 턴 자동으로 진행한다.
4. 키보드: `1`~`5` 기술 선택, `Q` 자동 편성, `Enter` 개시, `Esc` 전투 메뉴.
5. 지면 **같은 편성으로 재도전 / 편성 다시 / 쉬움으로 낮추고 재도전 / 타이틀**을 고를 수 있다. 진행이 막히는 일은 없다.

## 전투 시스템

림버스 컴퍼니의 전투 구조(속도·합·코인·정신력·흐트러짐)를 참고해 **이름·용어·수치를 새로 만든** 오리지널 시스템이다.

| 이 게임의 용어 | 규칙 |
|---|---|
| **속도 주사위** | 매 턴 모두가 굴린다. 보스는 주사위가 여러 개(=여러 번 행동). 적의 행동 칸에 속도·기술·표적이 공개된다. |
| **가로채기 / 반격 태세** | 내 속도가 더 빠르면, 다른 동료를 노린 적의 공격을 가로채 격돌한다. 느리면 일방 공격이 되고 적의 공격은 원래 표적을 친다. 일부 적(반격 태세)은 자기보다 느린 공격을 가로챈다. |
| **격돌** | 맞붙은 두 기술이 위력을 겨룬다. 위력 = 기본 위력 + 켜진 **등불** × 보너스. 진 쪽은 등불을 하나 잃고, 한쪽 등불이 다 꺼질 때까지 반복. 이긴 쪽이 남은 등불로 공격. |
| **심지** (-45 ~ +45) | 높을수록 등불이 잘 켜진다(0이면 50%, ±45면 약 90%/10%). 격돌 승리·적 격파·성가로 오르고, 격돌 패배·동료의 쓰러짐·일부 적 기술·**이야기 속 선택**으로 내려간다. -40 이하로 턴을 맞으면 **공황**(무작위 행동, 받는 피해 증가). |
| **자세 붕괴** | 체력 바의 흰 눈금(구간)에 닿으면 그 턴의 남은 행동과 다음 턴을 쉰다. 그동안 받는 피해 1.5배. |
| **기술 패** | 동료마다 기술 1·2·3을 정해진 비율(예 4:3:2)로 섞은 덱에서 매 턴 손패 2장을 유지. 쓴 카드만 새로 뽑는다. 수비는 언제나 가능. |
| **화음** | 한 턴에 같은 속성 기술을 2장 이상 쓰면 위력 +(장수-1)과 잔광 보너스, 3장 이상이면 심지 +3. 세라핀의 **무색** 기술은 어느 화음에도 합류. |
| **잔광 · 극의** | 격돌 승리·화음·피격으로 잔광이 찬다. 100이 되면 손패에 **극의**(궁극기)가 나타나고, 쓰면 컷인 연출. |
| **편성** | 합류한 동료(최대 6명) 중 전투마다 출전 인원(대개 3~4명)을 고른다. 이탈·사망으로 인원이 모자라면 적 체력이 줄고 시작 심지가 오른다. |
| **성장** | 동료마다 **각인** 3종(이야기 진행으로 해금) 중 하나를 장착. 전투 보상 **성흔 파편**으로 무기를 **단련**(체력·공격, 3단계부터 격돌 위력). 장이 진행될수록 레벨(위력)도 오른다. |
| **적** | 일반 / 정예 / 보스. 보스 기믹: **부위 파괴**(감독관 인형·별의 장부), **단계 전환**(율리안의 발검 등), **합창**(성가대 셋이 살아있으면 심지 감소), **개찬**(심지 뒤집기), **컨티뉴**(한 번 부활), **기록 봉인**(많이 쓴 기술 봉인), **쌍둥이 격앙**. |
| **난이도** | 쉬움(적 체력·피해 감소, 시작 심지 +10) / 보통 / 어려움(적이 더 단단하고 빠름). |

## 이야기

3막 구조: **1막 생존**(프롤로그·1장) → **2막 진실**(2·3장, 3장 끝 중반 반전) → **3막 대가**(4·5장·에필로그).
인물, 세계관, 장별 플롯, 복선과 회수 표는 [`docs/STORY_BIBLE.md`](docs/STORY_BIBLE.md)에 있다.

- 장마다 **일상**(수업, 기숙사, 무도회, 결투제, 야간 경계, 시험)과 **전투**가 번갈아 나온다.
- 선택에는 실제 대가가 있다: 동료의 **이탈**(카이엔 근신·롤랑 배신/도주·미레유의 떠남), **사망**(카이엔), **납치**(세라핀), **엔딩 분기**.
- 엔딩 3종: **TRUE 「이름을 부르는 자」 / NORMAL 「여백의 봄」 / BAD 「제49장」**. 트루 엔딩 조건은 플레이 중 단서(수첩)로 추리할 수 있다.

<details>
<summary>트루 엔딩 조건 (스포일러)</summary>

1. 지워진 이름 **다섯 개**를 모두 수첩에 적는다 — 핀 애셔(1장), 마르타 브라트(2장 명패), 엘레노어 로셰(3장 낱장), 헤스터 크레인(4장), 강이준(5장, 프롤로그 크레딧과 시계탑 낙서 ㄱㅇㅈ에서 추리).
2. 4장 갈림길에서 **세라핀을 놓치지 않는다**(시계탑으로 가거나, 3장에서 롤랑을 믿었다면 롤랑에게 기숙사를 맡긴다).
3. 마지막에 **"장부를 다시 쓴다"** 를 고른다. 조건이 모자라면 실패하고 노멀 엔딩으로 간다(무엇이 모자랐는지 알려 준다).

## 플레이 시간 추정

추정식: **(표시되는 대사 줄 수 × 줄당 읽기 시간) + Σ(전투별 평균 턴 수 × 턴당 시간 + 편성 10초)**

- 줄당 읽기 시간: 평균 29자 ÷ 초당 12자 + 클릭 0.4초 ≈ **2.8초**
- 전투 턴 수: 보통 난이도·단련 1단계에서 자동 전투 AI로 30회씩 시뮬레이션한 평균 (일반 2~4턴, 정예 4~5턴, 보스 4~9턴)
- 턴당 시간: 계획 12초 + 1배속 연출 13초 = **25초**
- 재현: `node tools/playtime.js` (턴당 초를 인자로 바꿀 수 있다)

| 구간 | 보는 줄 | 읽기 | 전투 수 | 전투 | **합계** |
|---|---|---|---|---|---|
| 프롤로그 | 199 | 8.5분 | 2 | 2.9분 | **11.4분** |
| 1장 | 276 | 12.1분 | 4 | 8.8분 | **20.9분** |
| 2장 | 213 | 10.4분 | 4 | 6.7분 | **17.1분** |
| 3장 | 198 | 9.5분 | 5 | 10.6분 | **20.1분** |
| 4장 | 195 | 9.7분 | 5 | 9.4분 | **19.0분** |
| 5장 | 110 | 5.6분 | 4.5 | 10.5분 | **16.1분** |
| 에필로그 | 26~90 | 1.4분 | 0 | 0 | **1.4분** (트루 엔딩은 약 4분) |
| **합계** | **약 1,220줄** | **57분** | **24.5회** | **49분** | **약 1시간 46분** |

- 숫자로 보면: 1,220줄 × 2.8초 ≈ 57분, 일반 10회 × 1.2분 + 정예 7회 × 1.9분 + 보스 7.5회 × 3.0분 ≈ 49분.
- 전투 2배속·자동 전투를 섞으면(턴당 18초) **약 1시간 34분**, 장당 평균 약 13~15분.
- 본편 1~5장은 장당 16~21분으로 요청한 10~15분보다 조금 길다. 대사 1,500줄 이상과 전투 20회 이상을 모두 담으면서 반복 전투를 넣지 않다 보니 생긴 차이로, 전투 연출을 2배속으로 두면 범위 안에 든다.
- 여러 엔딩을 보려면 2회차 이상: 이미 읽은 대사는 스킵되므로 2회차는 전투 위주로 약 50분 안팎.

```
@name 핀 애셔                      수첩에 이름 기록   @clue …  단서 기록
@resolve lennox -8                 이야기에 따른 심지 변화
@chapter ch1 | 제목 | 부제          장 표지 + 자동 저장
@ending true                       엔딩
```

문법 전체는 `js/story.js` 상단 주석에 있다. 고친 뒤 `node tools/validate.js`로 라벨·배경·인물·전투 참조와 모든 분기의 엔딩 도달 여부를 확인할 수 있다.

## 이미지 넣기

1. [`docs/IMAGE_PROMPTS.md`](docs/IMAGE_PROMPTS.md)의 경로 그대로 PNG를 저장한다. (공통 스타일 문구가 맨 위에 있다)
2. `node tools/scan_assets.js` 실행 → `data/assets.js` 갱신. (Node가 없으면 `files` 배열에 직접 경로 추가)
3. 새로고침. 이미지가 없는 항목은 계속 색 블록 + 이름으로 표시된다.

> 매니페스트를 쓰는 이유: 없는 이미지를 요청하면 브라우저 콘솔에 404 에러가 찍힌다. 매니페스트에 있는 파일만 불러와 콘솔 에러를 0으로 유지한다.

## 개발·검증 도구 (선택, Node 18+)

| 명령 | 내용 |
|---|---|
| `node tests/engine.test.js` | 전투 엔진 단위 테스트 (격돌, 가로채기, 자세 붕괴, 공황, 화음, 부위, 컨티뉴, 봉인, 전 전투 종료 보장) |
| `node tools/validate.js [회수]` | 시나리오 정적 검사 + 장별 분량 집계 + 무작위·지정 루트 플레이스루(모든 대사 도달, 트루/실패 조건 확인) |
| `node tools/battle_sim.js all 60 normal 1` | 자동 전투로 전투별 승률·평균 턴 측정 (밸런스 조정용) |
| `node tools/playtime.js` | 플레이 시간 추정 |
